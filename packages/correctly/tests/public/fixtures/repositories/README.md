# Repository fixtures

Configuration snapshots taken on October 1, 2026 from `/home/jem/lasertag`, `/home/jem/wayforge`, `/home/jem/recoverage`, and `/home/jem/agents.yaml`. The original `$schema` fields are retained as ordinary data.

`changesets.schema.json` is the actual schema distributed with `@changesets/config` 4.0.1 (draft 2020-12). `dprint.schema.json` is the official [dprint v0 schema](https://dprint.dev/schemas/v0.json) (draft 7). Both are fixed local snapshots; tests run offline and do not depend on the original repositories or network. Schemas retain their upstream descriptive text. These fixtures protect practical dialect coverage, formatting independence and the single-command CI path.
