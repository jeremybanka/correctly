# PKL fixtures

`package.zip` is generated by `scripts/pkl-fixtures.ts`. It uses deflate compression and contains `Config.pkl` importing `nested/Value.pkl`; the latter declares a constrained integer. `Glob.pkl` imports `nested/*.pkl` and asserts that exactly one module matches; `nested/deep/Other.pkl` must stay outside that glob. The package tests provide the archive through an injected fetch function, with no external network dependency.
